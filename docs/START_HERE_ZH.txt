项目 2 新增实际训练交付说明

这次实际训练了什么
从 ImageNet 初始化独立训练 6 个新模型。种子为 664、665、666，每个种子配对普通增强和强裁剪/颜色增强，各 8 轮。每轮重新为每张训练图像采样视图；不再重复两个固定随机视图。
每个模型完成 1,008 次优化、96,288 次图像呈现；合计 48 个 epoch、6,048 次优化、577,728 次呈现。使用一张 RTX 5070 Ti Laptop GPU，训练记录、所有权重、全部测试预测均包含在包内。
所有 6 个 checkpoint 只由 PlantVillage 验证集选择，并在测试评分前锁定哈希。没有按田间成绩挑选最好种子。
训练结束后又独立解码原始测试图像，重新加载全部 6 个模型，24,558 个预测类别完全一致，概率最大差异小于 0.000312。复算器已按训练协议恢复确定性与 TF32 设置，初始配置差异和修复记录一并保留。

优先打开哪些文件
submission/Tomato_Project.ipynb：37 个单元、21 个代码单元已顺序运行并保存输出；包含真实训练函数、各次训练曲线、指标和 bootstrap 重算、逐类差距及新权重实际推理。默认全部运行不会重训或下载原始数据。

project/results/fresh_views/：新增实验。原实验仍在 project/results/ 根层，保持分离。

新结果（三种子均值 ± 样本标准差，单位百分比）
                         普通训练          强增强
干净准确率               97.26 ± 0.16      96.66 ± 0.58
田间准确率               18.78 ± 1.10      20.13 ± 0.74
干净 macro-F1            96.32 ± 0.18      95.71 ± 0.50
田间 macro-F1             7.76 ± 0.83       9.16 ± 0.73

每个种子的田间准确率变化（强增强减普通）：
664：-0.27 个百分点；665：+3.10；666：+1.21。
平均 +1.35 ± 1.69 个百分点；macro-F1 平均 +1.40 ± 1.31。
因此新结论是“平均有小幅改善，但收益依赖种子，田间表现仍弱”。不能只写旧单种子负结果，也不能声称增强稳定有效。

与原实验的关系
原 ZIP 的两组权重、训练记录和预测没有改写。原两固定视图实验的结论仍是未见收益。
本次确实执行了新训练，但不是对原训练历史逐步完全重现。新旧运行环境、随机数实现和数据流也不同，因此新旧绝对差异不是只改变“视图刷新”的纯消融。主要受控比较是新环境内普通训练与强增强的配对实验。

最重要的方法文件
project/prepare.py：数据映射、官方切分、验证划分及去重。
project/experiment_fresh.py：新增三种子训练与评估。
project/summarize_fresh.py：预算/顺序/初始化审计和种子统计。
project/analyze.py、verify.py、evaluate.py：逐张结果分析、独立校验、原始图像权重复算。
project/experiment.py 保留旧训练实现并提供共享模型结构。

如何演示
先按 project/README.md 安装 Python 3.12 的展示环境，在 project/ 中运行：
python demo.py examples/field.jpg
python demo.py examples/field_second.jpg
默认使用事先指定的 seed 664 新权重。第一张两个新模型均预测 late blight（标签为 early blight）；第二张普通模型为 early blight，强增强为 late blight。案例没有根据新分数重新选择。
要演示旧权重，加 --results results。不能把 softmax 当作可信诊断概率。

如何重训
新训练使用独立 requirements-train.txt 环境（torch 2.7.1 / torchvision 0.22.1）；展示 Notebook 使用 requirements-notebook.txt（已验证 CPU torch 2.5.1 读取新权重）。不要混用固定版本。命令、单 GPU 集群模板与原始数据下载器均见 README。

仍然保留的局限
mosaic virus 没有验证样本，选择只覆盖八类，测试覆盖九类。
4,280 张训练图、1,060 张干净测试图缺少叶片 ID。字节审计不能排除未知同叶或近重复。
田间 spider mites 只有两张相关拼图。增加种子不会增加独立田间图片数量。
三个种子仍少；图像 bootstrap 与训练波动是不同的不确定性。
新方案是在看过原始田间结果后设计的探索性后续实验，不能称为全新、从未查看过的确认性外部测试。
